# Travel Planner: A Budget-Friendly Travel Planning Web Application

## 1. Project Overview

**Travel Planner** is a responsive web application designed to simplify trip planning by providing destination information, estimated travel costs, accommodation details, and optimized travel recommendations in a single platform. The system aims to help users make informed travel decisions, manage expenses effectively, and create budget-friendly itineraries for popular tourist destinations in Bangladesh.

---

## 2. Problem Statement

Planning a trip often requires users to gather information from multiple sources regarding transportation, accommodation, tourist attractions, and travel expenses. This process can be time-consuming and may lead to inefficient budgeting. Therefore, a centralized platform is needed to simplify trip planning and help travelers make cost-effective decisions.

---

## 3. Project Objectives

The primary objectives of this project are:

1. To develop a modern and responsive travel planning website.
2. To provide detailed information about popular tourist destinations in Bangladesh.
3. To estimate transportation expenses for different trips, accommodation costs.
4. To provide an estimated overall trip budget.
5. To recommend popular attractions and must-visit places.
6. To suggest nearby locations that can be visited conveniently together.
7. To allow users to maintain a personalized wish list of destinations.

---

## 4. Key Features

### 4.1 Destination Exploration

- Browse a curated list of popular tourist destinations in Bangladesh.
- View high-quality destination images and detailed descriptions.

### 4.2 Destination Information

- Display division and location details for each destination.
- List of popular attractions.
- Recommended restaurants and local eateries.
- Information on local markets and shopping areas.

### 4.3 Trip Cost Estimation

- Transportation cost calculation (e.g., bus, train, or airfare).
- Accommodation cost estimation for various budgets.
- Calculation of an overall trip budget summarizing all expenses.

### 4.4 Travel Recommendations

- Highlight must-visit attractions within a destination.
- Suggest nearby places that can be visited together for a more efficient and enjoyable trip.

### 4.5 Wishlist Management

- Allow users to save preferred destinations for future trips.
- Provide functionality to view and manage a personal list of favorite locations.

## 6. System Architecture

The system follows a standard **three-tier architecture**, providing a clear separation of concerns for maintainability and scalability.

- **Presentation Layer (Frontend):** Built with HTML, Tailwind CSS, and JavaScript. This layer handles the user interface and client-side interactions.
- **Application Layer (Backend):** Built with PHP. This layer contains the core business logic, processes user requests, and communicates with the database.
- **Database Layer (Backend):** Managed by MySQL. This layer is responsible for storing, retrieving, and managing all persistent data, such as destination details, costs, and user wishlists.
